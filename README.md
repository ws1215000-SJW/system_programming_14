## 직원 콘솔

Linux 또는 WSL에서 `make` 후 저장소 루트에서 `./worker`를 실행합니다. 직원은
`go cooling`, `go power`, `go generator`로 이동합니다. `help`는 일반 명령의 사용법과 예시, `status`는 최근 계측 보고, `cat 파일명`은 현장 단서를 표시합니다.

G03은 실제 POSIX 권한 `0000`과 `0640`을 사용합니다. 원래 저장소에서
`./worker`를 실행하면 권한 변경을 확인합니다. WSL의 Windows 드라이브처럼
권한이 반영되지 않는 곳에서는 현장 데이터만 Linux 임시 폴더에 복사해 사용하고
게임 종료 시 정리합니다. 다음 실행은 새 현장으로 시작합니다.

터미널에서 실행하면 직원 콘솔은 ncurses 화면(`src/ui.c`)으로 뜹니다. 머리줄에 진행 중인
이벤트와 남은 시간, 오른쪽에 지금 있는 시설의 계기판이 보입니다. 파이프로 입력을 주거나
`WORKER_PLAIN=1`을 주면 예전처럼 줄 단위로 출력합니다.

‘추가 조작 필요’는 설정·설비를 다시 조사해야 한다는 뜻입니다. ‘회복 확인 중’이면
재입력 없이 계측 보고를 기다리세요.
